# When Her Smile Takes Away Yours: Google Flow version

The same audio, timing and storyline as the chalkboard version, but built from **3D animated-movie images** made in Google Flow.
I'll add all the motion myself: camera moves, shakes, falls, lip-sync, captions, and overlays like the love meter, the 0% battery, "CRASH!", "HAHAHA", tears and hearts.

**Before you start:**
- Make the 4 character sheets first.
- Add them as **ingredients** in every prompt that uses that character.
- Set the aspect ratio to **9:16**.
- File names don't matter. Send them in any order, like before.

**For lip-sync pairs:** make the **OPEN**-mouth image first. Then use Flow's **Edit**, paint over just the mouth, and type *"mouth closed, small smile"*. Everything else must stay identical.
